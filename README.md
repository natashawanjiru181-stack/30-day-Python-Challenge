- Data Structures in Python (6):
   - Dictionary-key value pairs, curly brackets
   - Set-unordered, no duplicates, curly brackets
   - Tuple-immutable;once created cannot be changed, curved brackets
   - List-ordered, mutable, box brackets
   - Range-only integers, leaves out the last number, curved brackets
   - Frozenset-behaves like a set but unorderd cannot be changed after creation, stores any type of value, curved then box brackets
- Data Types in Python (12):
   - (1-6) all the data structures
   - int-integers
   - float - Numbers with decimals
   - complex - Written as a + bj (Python uses j for √−1)
   - str - (String / Text), Any sequence of characters in quotes
   - bool - (Boolean), Only two possible values: True or False
   - NoneType - Represents the absence of a value. Used when something returns None
